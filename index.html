Inżynieria Infrastruktury & Bezpieczeństwo

Posiadam komercyjne doświadczenie w zarządzaniu produkcyjnymi środowiskami IT (m.in. w Lehmann + Partner Polska oraz CorpoTech). Moim celem jest budowanie niezawodnej, przewidywalnej infrastruktury opartej na zasadach Zero Trust, automatyzacji powtarzalnych czynności oraz proaktywnym wykrywaniu anomalii.

W codziennej pracy nie ograniczam się do szablonowych zadań administratora. Tworzę również autorskie oprogramowanie wspierające inżynierów (Python/Flask, API, webhooki), co pozwala eliminować ludzkie błędy i drastycznie skracać czas reakcji na incydenty.

// 03. CASE_STUDIES

Wdrożenia & Architektury Inżynierskie

Program Zgodności NIS2 / UKSC & Linux Server Hardening

CYBERSECURITY NIS2 / UKSC ANSIBLE LINUX HARDENING

Kompleksowe przygotowanie i adaptacja infrastruktury serwerowej do wymogów Europejskiej Dyrektywy NIS2 oraz Ustawy o Krajowym Systemie Cyberbezpieczeństwa. Projekt objął wewnętrzne audyty podatności, analizę ryzyka, opracowanie procedur Disaster Recovery oraz stworzenie zautomatyzowanych playbooków Ansible do utwardzania (hardeningu) systemów Debian/Ubuntu i Windows Server.

  • Audyt bezpieczeństwa kont, uprawnień i usług sieciowych
  • Zautomatyzowany hardening SSH, firewalli UFW/iptables, fail2ban
  • Wdrożenie polityki najmniejszych uprawnień (Least Privilege)
  • Standaryzacja cyklu życia certyfikatów SSL/TLS i szyfrowania danych

Zabbix-Signal Alerting System (Real-Time Dispatcher)

ZABBIX API PYTHON SIGNAL REST API MONITORING

Autorski mikromoduł w języku Python integrujący komercyjne środowisko Zabbix z API szyfrowanego komunikatora Signal. System filtruje zdarzenia infrastruktury w czasie rzeczywistym, wysyłając natychmiastowe, sformatowane notyfikacje o krytycznych awariach i anomaliach sprzętowych bezpośrednio do inżynierów dyżurnych.

  • Czas dostarczenia powiadomienia o awarii serwera poniżej 5 sekund
  • Filtrowanie alertów i unikanie zjawiska alert fatigue (szumu)
  • Bezpieczna komunikacja z REST API z autoryzacją tokenem
  • Pełne logowanie incydentów i mechanizm ponawiania przy braku sieci

TesterApp – Dedykowana Platforma Automatyzacji QA

PYTHON (FLASK) SQL QA AUTOMATION RAPORTOWANIE

Zaprojektowanie i wdrożenie produkcyjnej aplikacji webowej w Python (Flask) mającej na celu wyeliminowanie czynnika ludzkiego w procesach kontroli jakości i testowania oprogramowania. Aplikacja dynamicznie generuje scenariusze testowe, wymusza załączanie materiału dowodowego (weryfikacja fotograficzna) i automatycznie kompiluje ustandaryzowane raporty.

  • Obsługa rozbudowanej bazy ponad 200 dynamicznych scenariuszy pytań
  • Weryfikacja integralności zdjęć i blokada pomijania procedur kontroli
  • Redukcja błędów ludzkich podczas odbioru oprogramowania o ponad 80%
  • Automatyczny eksport zestawień analitycznych dla kadry zarządzającej

Produkcyjne Środowisko Wirtualizacji Proxmox VE

PROXMOX VE ZFS STORAGE LXC / KVM PBS BACKUP

Wdrożenie lokalnego środowiska wirtualizacyjnego o wysokiej dostępności opartego na hypervisorze Proxmox VE w firmie Lehmann + Partner Polska. Realizacja objęła konfigurację sprzętową, pulę dyskową ZFS z redundancją, wdrożenie lekkich kontenerów aplikacyjnych LXC oraz politykę deduplikowanych kopii zapasowych (Proxmox Backup Server).

  • Wysoka gęstość upakowania usług dzięki kontenerom aplikacyjnym LXC
  • Ochrona danych na poziomie ZFS snapshots i szyfrowanych kopii PBS
  • Izolacja sieciowa pomiędzy środowiskami produkcyjnymi i testowymi
  • Wyczerpująca dokumentacja Disaster Recovery skracająca ewentualny RTO
